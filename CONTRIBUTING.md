# Contributing to BrainChain

Thank you for helping improve BrainChain. Each repository has its own development guide in its README; this page covers what applies everywhere.

## Ways to help

- **Report a bug** with a minimal reproduction.
- **Propose a change** in an issue before writing code, so we can agree on the approach.
- **Improve the docs.** Clear explanations of how the chain decides are as valuable as code.

Security issues never go in public. See [SECURITY.md](SECURITY.md).

## Pull requests

- One change per pull request, with a description of what it does and why.
- Tests for every behaviour change.
- Formatting and tests pass locally before you push; CI runs both.
- Documentation and the changelog are updated where behaviour changes.

By contributing, you agree that your contributions are licensed under the license of the repository you contribute to.

## Conduct

Everyone taking part follows our [Code of Conduct](CODE_OF_CONDUCT.md).
